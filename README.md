# 客户管理系统（阀门行业版）

面向阀门销售的个人客户与项目管理软件。**单机运行、默认无需登录、数据全部留在本机**，
双击 `启动.bat` 即用。想在手机 / 异地访问时，可再开启**可选登录 + 监听范围 + 隧道**。

当前版本 **1.25** · 详见 [CHANGELOG.md](CHANGELOG.md) · 文档索引见 [docs/README.md](docs/README.md)

---

## 特点

- **零依赖**：后端只用 Node.js 内置模块（`node:sqlite` + `node:http`），
  前端 Vue 3 / ECharts / SheetJS 全部内置于 `web/vendor/`。
  **无需 `npm install`，无需任何联网配置，离线可用。**
- **一客户一项目**：客户资料只有 4 个区块 16 个字段，项目档案、回款与成本都在客户详情里，
  不再有独立的「项目管理」模块。
- **登录是可选的**：默认**不启用登录、只监听 `127.0.0.1`**，打开即用；
  要在手机 / 异地访问，再开启登录并选择监听范围（详见下文「登录与异地访问」）。
- **数据不出本机**：服务默认只监听 `127.0.0.1`；除「邮件提醒」（可选、默认关闭）外，
  全程零外部网络请求。异地访问用的 Tailscale / Cloudflare Tunnel 只是网络通道，不接触业务数据。
- **真实 Excel**：导出为 `.xlsx`（中文不乱码、数值可参与计算），导入带校验与预览。

## 快速开始

1. 安装 [Node.js](https://nodejs.org/) 20 或更高版本（本项目在 v24.21.0 上开发验证）
2. 双击桌面/开始菜单的「**CRM管理系统**」图标（或 `启动.bat`）
   —— 会自动建库、启动服务，并打开一个**无地址栏的应用窗口**
3. **启动后没有命令行窗口**（服务在后台跑）；要停止：设置页「关于 → 停止服务」
   运行日志在 `data/server.log`（超过 5MB 自动轮转一份）

数据存放在 `data/` 目录（数据库、附件、备份），在资源管理器里直接打开即可。

> 只保留这一个启动器：原来单独的「停止」「安装为应用」「打开数据目录」脚本已合并/删除；
> 桌面快捷方式通过 `启动.vbs` 调起 `启动.bat`（完全无窗口），图标是订制的 Q 版女仆。

## 功能模块

| 模块 | 说明 |
|---|---|
| **首页总览** | 6 张指标卡（客户数 / 待回访 / 本月收入 / 本月利润 / 本月成本 / 应收未收）+ 回访提醒 + 收入报表（按月/按年，含采购成本与利润）+ 客户地区/行业分布环形图 + 今日待办 + 最近动态 |
| **客户管理** | **一客户一项目**：客户只有 4 区块 16 字段（公司名称 / 客户编号 KH-YYYY-0001 / 行业 / 来源 / 标签 / 地址与归属地州 / 主联系人 / 回访周期 / 备注）；列表可按行业、来源、地州、标签筛选；固定标签 5 个 + 自定义；查重、回收站、批量导入导出 |
| **产品价目表** | **三级分类树 + 产品价**：一级＝阀门大类（蝶阀 / 球阀 / 止回阀 / 隔膜阀 / 刀闸阀 / 执行器 6 个固定，可改名、不可删）；二级＝按结构（衬胶蝶阀 / 三偏心蝶阀 / 浮动球阀…，共 22 个）；三级＝按连接 / 法兰安装方式（对夹 / 法兰 / 支耳 / 螺纹 / 焊接 / 法兰连接 / 支架连接，共 46 个）；**二级、三级都是自定义分类，可改名、可挪位、可删除**，也能继续往下细分（种子合计 74 个，不要就删）；产品字段＝名称 / 编号 / 单位 / 单价 / **货期(周，精确存储)** / 阀体材质 / 压力等级 / 设定折扣 / 备注 / 启用；**折后价 = 单价 × (1 − 折扣/100) 自动算**；按分类（一级默认带出三级产品）/ 关键字 / 材质 / 压力 / 状态筛选与分页；一键复制产品；**Excel 批量导入**（分类不存在可自动创建）；导出 `产品价目表-YYYYMMDD.xlsx` |
| **待办中心** | 跟进计划、回款提醒、手动待办汇总到一处 |
| **登录与异地访问（可选）** | 默认关闭。设置密码后可启用登录；同一 IP 连错 5 次锁 15 分钟；IP / CIDR 白名单；监听范围三档（仅本机 / 局域网 / 全部，切换需重启）；改密后所有旧登录立即失效；登录 / 失败 / 退出 / 改密 / 监听变更全部写审计（不含密码）；设置页内置 **Tailscale / Cloudflare Tunnel / 公网 IPv6** 三套免费方案的操作指引 |
| **功能设置** | 字典管理、标签、提醒偏好、**登录与异地访问**、备份恢复、导入导出、附件存储、回收站、操作日志、关于 |

> 客户详情 4 个标签页：**资料**（含财务汇总栏 + 附加联系人折叠）、**回访与跟进**、
> **项目与财务**（项目档案 / 回款计划与实收 / 成本台账 / 历史项目只读）、**附件与日志**。
> 一客户只能有一条「当前项目」，换项目时把旧项目「转为历史」即可（历史只读、账目保留）。

## 财务口径

| 指标 | 公式 |
|---|---|
| 合同额 | 当前项目档案上的合同额 |
| 已收 | Σ 实收流水 |
| 应收 | Σ 回款计划 − 已收（负数按 0 显示） |
| 采购成本 / 维护成本 / 其他成本 | 成本台账分类汇总（其他 = 差旅 + 其他） |
| **毛利（实际）** | **已收 − 采购成本 − 维护成本 − 其他成本** |
| 毛利率 | 毛利 ÷ 已收（已收为 0 显示「—」） |
| 预计毛利 | 合同额 − 采购成本 |

## 客户分布与收入报表

首页不用地图，改成**两张环形图 + 一张收入报表**，一屏看清"客户在哪、钱从哪来、赚了多少"：

- **客户地区分布**：按地州统计（客户填了「市/地区」自动归属；地址识别不了的单独记为"未归属"）
- **客户行业分布**：按行业统计，也可切换成「按来源」「按标签」
- **收入报表**：收入（实收）按日期归月/归年；成本分**采购成本 / 维护成本 / 差旅 / 其他**四类记账；
  **利润 = 收入 − 全部成本**，毛利率 = 利润 ÷ 收入；点某个月可下钻看逐笔明细
- 成本在客户详情「项目与财务 → 成本台账」里登记（采购成本可填供应商）；不记成本时利润就等于收入

## 批量导入客户

客户管理页右上角 → **批量导入**：

1. 下载模板（`.xlsx`，含「导入模板 / 填写说明 / 可选值参考」三页）
2. 按模板填写，拖回抽屉
3. 先校验预览（哪行有问题、为什么），确认后导入

重名的行可选**跳过**或**更新已有记录**（更新时只覆盖表格里填了的列，留空的保留原值）。

## 批量导入产品

产品价目表页右上角 → **批量导入**：

1. 下载模板（`.xlsx`，含「导入模板 / 填写说明 / 可选值参考」三页）
2. 分类路径按 `蝶阀 / 三偏心蝶阀 / 对夹`（或 `蝶阀>三偏心蝶阀>对夹`）填写；产品名称、单位、单价、货期(周)、材质、压力等级、折扣、启用、备注按模板填写
3. 拖回抽屉 → 校验预览：同分类重名可选**跳过 / 更新**，分类不存在时可勾选**自动创建**（默认勾选）
4. 确认导入后自动刷新分类树与产品列表

> 货期在界面与导入模板里都按**周**填写（可一位小数，如 3.5），v15 起精确存 `lead_time_weeks`，
> 3.5 周保存后回显仍是 3.5 周；同时冗余存 `lead_time_days`（`Math.round(周 × 7)`）供旧字段/导出兼容。
> 产品编号可留空；非空时全库唯一，重复会整行报错；单次最多导入 2000 行，空行自动跳过。

## 备份与恢复

- 每天首次启动自动备份：主目录保留 30 份，镜像目录保留 7 份
- 设置 → 备份与恢复：可手动备份、校验完整性、从备份恢复（恢复前自动再做一次兜底备份）
- ⚠ 附件存放在 `data/attachments`，**不包含在数据库备份里**，换机时需一并拷贝

## 邮件提醒（免费、不需要登录）

每天早上到点自动把"今天该跟进/回访的客户"发到你的邮箱：

- 用自己邮箱的 **SMTP 授权码** 即可（QQ / 163 / 126 / 腾讯企业邮 / 天翼 189），**不需要购买任何服务**
- 发送是服务进程内的定时任务，**不需要打开页面、也不需要登录**；电脑开着、服务在跑即可
- 设置 → 提醒与偏好 → 邮件提醒：填写服务商、授权码、收件人，点"发送测试邮件"验证
- 未启用时不建立任何网络连接；当天没有待跟进客户则不发空邮件

## 登录与异地访问（可选）

**默认不启用登录，只监听 `127.0.0.1`**——和 1.24 一样打开即用，其他设备根本连不上。
只有当你想在手机 / 外网使用时，才需要开启这套能力：

1. **设置 → 登录与异地访问** → 设置登录密码（至少 6 位）
2. 打开「启用登录」
3. 监听范围选「局域网」或「全部网卡」→ 保存后**关闭服务窗口，重新双击 `启动.bat`**（监听地址不能热改）
4. 让手机和电脑进入同一虚拟内网（推荐 Tailscale），手机浏览器打开 `http://100.x.x.x:8899`

**安全机制**

- 密码只存 **scrypt 加盐哈希**（salt 16 字节、N=16384 r=8 p=1），明文不落库、不回传、不进日志
- 会话是服务端签名的 **HttpOnly Cookie**（`SameSite=Lax`，30 天），退出登录即清除
- 同一 IP **连续 5 次密码错误锁 15 分钟**，锁定期间正确密码也拒绝；登录成功清零
- 可选 **IP / CIDR 白名单**（如只允许 Tailscale 网段 `100.64.0.0/10`），名单外的请求一律 403，且不区分密码对错
- **改密码后所有旧登录立即失效**（会话密钥轮换）；改用户名同理
- 登录成功 / 失败 / 退出 / 改密 / 监听范围变更都写进「操作日志 → 对象类型 auth」，含 IP 与时间，**不含密码**
- **忘记密码**：先关闭服务，在本机执行 `node tools/reset-password.js`（清空密码并关闭登录），重启后再设新密码

**三套免费方案**（设置页里有逐步操作指引，每套 5 步以内）

| 方案 | 费用 | 手机侧 | 什么时候选它 |
|---|---|---|---|
| **A. Tailscale（推荐）** | 0 元（免费版最多 6 个用户、**设备数量不限**） | 装 Tailscale App，访问 `http://100.x.x.x:8899` | 不想买域名、要最安全（不对公网开端口） |
| **B. Cloudflare Tunnel** | 0 元 + 域名 10~30 元/年 | 浏览器直接开 `https://crm.你的域名` | 想发个链接就能在微信里打开 |
| **C. 公网 IPv6 + DDNS** | 0 元 | 手机需支持 IPv6 | 宽带有公网 IPv6、不想装客户端 |

> 三种方案都**不会把数据放到云上**：数据库仍是本机的 `data/crm.db`，隧道只负责网络转发。
> 共同前提是先设登录密码；**不要把端口直接裸奔到公网**，一定要开登录并尽量配白名单。

## 开发与测试

```bat
:: 启动服务（开发模式，前台运行便于看日志）
:: CRM_ROOT 指向本项目所在目录，CRM_PORT 可省略（默认 8899）
set CRM_ROOT=%~dp0
set CRM_PORT=8899
node server\server.js

:: 一键跑全部测试套件（默认在 .fixtures/sandbox 沙箱副本里跑，不碰真实 data/）
node tools\run-all-tests.js

:: 忘记登录密码（本机、停止服务后执行；清空密码并关闭登录）
node tools\reset-password.js

:: 生成演示数据，便于看界面效果
node tools\seed-demo-data.js

:: 界面截图（输出到 .shots/）
node tools\screenshot.js --tag review
```

本地模拟 SMTP 服务器上的完整发信流程、自带隔离实例的「登录 / 会话 / 锁定 / 白名单 / 审计」安全专项，
以及「一客户一项目」「产品分类与折后价」专项测试。
