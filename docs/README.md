## 三、维护约定

1. **新方案**一律放 `docs/方案/`，文件名用中文，不带版本号后缀
   （版本变化在文档内部的「修订记录」里体现，避免文件名与内容版本对不上）。
2. **验收报告**放 `docs/验收报告/`；一次性排查结论若需要留档，追加到对应报告或
   `CHANGELOG.md`，不要散落在仓库根目录。
3. **每完成一个功能或修一个缺陷**：升版本号 → 写 `CHANGELOG.md` 条目
   （现象 → 根因 → 修复 → 影响文件 → 验证）→ 全量回归 → 提交并打标签。
4. 文档里的路径引用请写成**相对仓库根**的形式（如 `docs/方案/后续功能_技术方案.md`），
   便于从任何位置打开都能找到。
