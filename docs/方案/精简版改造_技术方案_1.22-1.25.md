### 2.2 环形图怎么算

两张环形图（都放首页，可切换统计维度）：

1. **地区分布**：按 `region_name`（地州级）聚合，Top 8 + "其他"；点扇区跳客户列表并带筛选
2. **行业分布**：按 `industry` 聚合（石油/化工/电力/冶金/水处理…），同样 Top 8 + 其他
3. **来源分布**：按 `source` 聚合（工程公司配套 / 老客户介绍 / 展会…）

首页固定展示两张：**地区分布 + 行业分布**；每张图的右上角可下拉切换成"按来源"。

```
GET /api/stats/distribution?by=region|industry|source|tag&top=8
→ { ok, data: { total, groups: [{ key, label, count, percent }] } }
```

口径：`deleted_at IS NULL`；`region_name` 为空归入「未归属」，`industry` 为空归入「未填写」。

### 2.3 验收变化

- 删除地图相关 **6 项**（渲染 / 下钻 / 缩放 / 离线 / 坐标转换 / 审图号）
- 新增 **3 项**：分布接口口径正确、环形图与客户清单数字一致、点扇区可下钻

### 3.2 一客户一项目：项目并入客户（**已确认**）

**界面上没有"项目管理"模块了**，项目信息只出现在客户详情里。数据上保留一张**隐藏的 1:1 项目档案表**（`projects` 改造），原因是它还挂着回款、附件、待办和日志 —— 保留它就不用把这几张表的关联全部重接，迁移风险最小（界面效果与"合并进客户表"完全一致）。

| 项目档案字段（客户详情里编辑） | 说明 |
|---|---|
| 项目名称 `name` | 必填（客户可暂时没有项目） |
| 项目阶段 `stage` | 沿用 14 阶段字典，可自定义 |
| 项目进度 `progress` | 0~100% |
| 合同额 `contract_amount` | 预计收入，利润预估要用 |
| 签约日期 `signed_at` | — |
| 投标日期 / 结果 `bid_date` / `bid_result` | 保留（首页不再做日历，但在客户详情显示） |
| 交货期 `delivery_date` | — |

**1:1 怎么保证**：
- 加部分唯一索引 `UNIQUE(customer_id) WHERE deleted_at IS NULL AND archived = 0`
- 新增 `archived` 列：同一客户历史上如果有多个项目，最新那条为"当前项目"，其余标 `archived=1`，在客户详情"历史项目"折叠区只读展示
- 迁移时你的数据：项目 #515 → 克拉玛依石化分公司热电厂、#516 → 东方希望新材料，**两家客户各一个，不产生归档**
- 新建客户时项目区可留空；**第一次登记回款/成本时自动建一条空的项目档案**（保证财务数据有归属）

**删掉的页面/入口**：项目管理页、项目详情页、导航里的「项目管理」、客户列表的"项目数"列。
导航变为：**首页总览 / 客户管理 / 产品价目表 / 待办中心 / 功能设置**。

### 3.3 财务：收入、采购成本、维护成本、利润（**已确认要扣采购成本**）

**成本台账**（新增 `costs` 表，客户详情里登记）：

| 字段 | 说明 |
|---|---|
| 分类 `category` | **采购成本** / **维护成本** / 差旅 / 其他 |
| 金额 `amount` | ≥ 0 |
| 发生日期 `spent_at` | 按月/年报表用 |
| 供应商 `supplier` | 采购成本时填（可选） |
| 备注 `remark` | — |

**客户卡片上的财务栏**（全部自动算，只读 + 可下钻）：

| 指标 | 公式 |
|---|---|
| 合同额 | 项目档案上的 `contract_amount` |
| 已收 | Σ `payments` 实收 |
| 应收 | Σ `payments` 计划 − 已收（负数按 0 显示） |
| 采购成本 | Σ `costs` 分类=采购成本 |
| 维护成本 | Σ `costs` 分类=维护成本 |
| 其他成本 | Σ `costs` 分类=差旅+其他 |
| **毛利（实际）** | **已收 − 采购成本 − 维护成本 − 其他成本** |
| 毛利率 | 毛利 ÷ 已收（已收为 0 时显示「—」） |
| 预计毛利 | 合同额 − 采购成本（报价/投标时看这个） |

### 4.2 指标与报表口径（**利润扣采购成本**）

| 指标 | 口径 | 数据来源 |
|---|---|---|
| 本月收入 | Σ 实收（按 `actual_date` 归月） | `payments` |
| 本月采购成本 | Σ `costs` 分类=采购成本（按 `spent_at` 归月） | `costs` |
| 本月维护成本 | Σ 分类=维护成本 | `costs` |
| 本月其他成本 | Σ 分类=差旅+其他 | `costs` |
| **本月利润** | **本月收入 − 本月采购成本 − 本月维护成本 − 本月其他成本** | 计算 |
| 本月毛利率 | 本月利润 ÷ 本月收入 | 计算 |
| 应收未收 | Σ 计划 − Σ 实收 | `payments` |
| 按年 | 12 个月一组（收入/成本/利润/毛利率） | 同上 |

报表下钻：点某个月 → 该月的收入明细（客户/日期/金额）与成本明细（客户/分类/供应商/金额）。

### 4.3 接口

## 6. 需求五：异地登录（免费怎么实现）

### 6.1 方案对比

| 方案 | 费用 | 需要什么 | 手机怎么用 | 推荐度 |
|---|---|---|---|---|
| **A. Tailscale** | **0 元**（免费版最多 6 用户、设备不限） | 电脑与手机各装客户端，登录同一账号 | 装 App，访问 `100.x.x.x:8899` | ★★★★★ |
| **B. Cloudflare Tunnel** | 0 元 + 域名（10~30 元/年） | 一个域名托管到 Cloudflare；家里跑 `cloudflared` | 浏览器直接开 `https://crm.你的域名` | ★★★★ |
| **C. 公网 IPv6 + DDNS** | 0 元 | 宽带 IPv6、光猫桥接 | 手机需支持 IPv6 | ★★★ |
| D. ZeroTier | 0 元（免费版限节点） | 同 A | 装 App | ★★★ |
| E. 花生壳/蒲公英免费版 | 0 元（限速） | 装客户端 | 能 | ★★ |
| F. 自购 VPS + frp | 60~300 元/年 | 云服务器 | 能 | ★★ |

> Tailscale 免费版（Personal）：**免费永久、最多 6 个用户、设备不限**（[官方定价](https://tailscale.com/pricing)）。
> 三种方案都**不需要云数据库**：数据库仍在你家电脑的 `data/crm.db`，隧道只是加密链路。

### 6.2 软件必须补的功能

| # | 功能 | 说明 | 必须 |
|---|---|---|---|
| 1 | 登录页 + 密码 | scrypt 加盐哈希存设置项，首次开启时设置 | ✅ |
| 2 | 会话 | HttpOnly + SameSite=Lax Cookie，默认 30 天，可退出 | ✅ |
| 3 | 防爆破 | 同 IP 连续 5 次失败锁 15 分钟，写审计 | ✅ |
| 4 | 监听范围 | 三档：仅本机（默认）/ 局域网 / 全部；切"全部"必须已设密码 + 确认风险 | ✅ |
| 5 | 审计 | 登录成功/失败/退出（时间 + IP + 结果），可在操作日志查 | ✅ |
| 6 | HTTPS | 走 Cloudflare 由隧道自动 TLS；自主隧道可启用自签证书 | ⭕ |
| 7 | IP 白名单 | 只允许 Tailscale 网段 `100.64.0.0/10` | ⭕ 建议 |
| 8 | 二次验证 TOTP | 手机验证器，离线可用 | ⭕ 可选 |
| 9 | 只读模式 | 异地只看不改 | ⭕ 可选 |

**明确不做**：不做云同步、不把数据库放公网、无密码时禁止监听 `0.0.0.0`。

### 6.3 Tailscale 操作步骤（5 步）

1. 家里电脑装 Tailscale（Windows 客户端）并登录
2. 手机装 Tailscale（iOS/Android）登录**同一账号**
3. 软件里：功能设置 → 异地访问 → 设密码 → 监听范围选「全部」
4. Tailscale 后台看到家里电脑的 `100.x.x.x`；手机浏览器打开 `http://100.x.x.x:8899`
5. （可选）开启 MagicDNS，之后用 `http://电脑名:8899` 访问

优点：**不开公网端口、不做端口映射、端到端加密**。缺点：手机要装客户端，国内走中继速度一般（看图/操作够用）。

### 6.4 Cloudflare Tunnel（想"浏览器直接开链接"用这个）

1. 买便宜域名（`.top` 约 10~30 元/年）托管到 Cloudflare（免费套餐）
2. 家里装 `cloudflared`，创建 Tunnel 指向 `http://127.0.0.1:8899`
3. 绑定 `crm.你的域名`，自动 HTTPS
4. 软件里打开异地访问并设密码（公网地址，登录必须开）
5. 手机浏览器直接开

优点：无客户端、HTTPS 现成。代价：域名年费；公网地址必须有登录 + 防爆破（可再加 Cloudflare Access 免费邮箱验证）。

### 6.5 安全红线

- 没设密码就**禁止**把监听切到「全部」（直接拒绝）
- 登录成功/失败写审计，界面显示"最近登录 IP / 时间"
- 会话密钥随机生成并持久化，可一键"所有设备下线"
- 密码 ≥ 8 位且含字母+数字；连续失败锁定
- README 与设置页写明：Tailscale / Cloudflare 只是网络通道，不接触业务数据

### 6.6 验收（6 项）

1. 未设密码时不允许开「全部」监听
2. 登录发会话、刷新不掉线；退出后 401
3. 连续 5 次错密码锁 15 分钟并写审计
4. 开启监听后另一设备可访问（同机双端口模拟）
5. 审计日志含时间/IP/结果，不含密码
6. 改密码后旧会话失效
